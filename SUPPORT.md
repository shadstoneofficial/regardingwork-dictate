# Support

RegardingWork Dictate is currently a macOS pilot.

## Before requesting help

1. Confirm you are using the latest supported release.
2. Open the waveform menu-bar icon and choose **Setup & Diagnostics…**.
3. Review the setup, permissions, uninstall, rollback, and manual-test
   instructions in [PILOT.md](PILOT.md).
4. Search existing GitHub Issues.

For a non-sensitive bug, open a GitHub Issue with:

- macOS version and Mac model or chip family
- RegardingWork Dictate version
- the application where text insertion failed
- expected and observed behavior
- sanitized reproduction steps

Do not attach recordings, transcripts, credentials, signing material, or other
personal data. Describe the shape of the problem using invented text instead.

## Security and privacy reports

Do not report suspected vulnerabilities or privacy incidents in a public
issue. Follow the private reporting process in [SECURITY.md](SECURITY.md).

## Scope

The current release supports Apple silicon Macs running macOS 14 or later.
Intel Macs, iPhone, iPad, Windows, Android, cloud transcription, meeting
capture, accounts, and server features are not currently supported.
